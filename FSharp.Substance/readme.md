FSharp.Substance 语法解析器，解析fsharp light implimentation文件。

解析器仅保留语义表达式，不保存文本文件的具体输入格式。

# 词法简化

只支持单行的`(*...*)`注释，不支持跨行，比如：

```fsharp
let x (*arg*) a = ...
```

只支持Json字符串格式，不支持原义字符串`@"`，三引号字符串`"""`。

只支持JSON数字格式。不支持小数点开头结尾，下划线分割符号。

```fsharp
.1;
1.;
1_000;
```

不支持自定义运算符重载，必须FSharp中已经定义好的运算符重载，且不能改变优先级。

# 语法简化

不支持let in表达式

```fsharp
let x = 5 in x
```

对于多行语句，要么所有同在1行，要么每行1项。
仅行首的缩进有约束，非行首的位置不构成约束，被忽略。

```fsharp
let x = let y = 0
        2*y
```

悬垂式需要记住非行首token的位置，比如let y的位置，2*y和他对齐。要解决这种情况，应该在等号后面换行

fantamos.aligned模式

```fsharp
let x =
    let y = 0
    2 * y
```

单行时候支持右边是元组，不能有分号。

```fsharp
let x = 2,3
```

换行会补充省略的左边界和右边界，分号会补全省略的右边界。

续航要符合表达式的层次嵌套关系，不能底层高优先级表达式换行而高层低优先级表达式不换行。

显示的括号`(){}[]`是不会自动补全的，缩进计算不能跨越不匹配的括号。隐式LLPAREN,RRPAREN不计较。

命名括号表达式，前缀名称和括号之间不要换行：
```fsharp
seq {}
Map []
task {}
set []
```

借代：左边界为None时候，可以借代父结点的左边界。左边界如左括号，fun ->等结构
